JoyHarness · 安装与配置

把 Joy-Con 接到电脑上

准备一台运行 macOS 15 或更新版本的 Apple Silicon Mac，以及一只 Joy-Con 或 Joy-Con 2。
按顺序完成配置，也可以直接跳到需要的部分。

下载 Apple Silicon 版 DMG，打开后将 JoyHarness.app 移入「应用程序」。

首次使用 · 安装应用

  1. 打开下载的 DMG，将 JoyHarness.app 拖入「应用程序」。
  2. 从「应用程序」启动 JoyHarness，进入应用的「设置」，按提示授予辅助功能权限。
  3. 根据手柄型号继续配对。授权后如果 macOS 提示退出应用，从菜单栏退出 JoyHarness，再从「应用程序」打开。

关闭主窗口后，JoyHarness 会继续在菜单栏运行。点击菜单栏图标可重新打开面板、暂停映射或重新扫描。

01 · 配对与授权

连接 Joy-Con

  1. 打开 macOS「系统设置 → 蓝牙」。长按手柄侧轨上的 SYNC 按钮，然后选择 Joy-Con (L) 或 Joy-Con (R) 进行配对。
  2. 回到 JoyHarness，在「设置」中按提示授予输入监控与辅助功能权限，按系统提示重新打开应用。
  3. 在顶部设备菜单或「连接与摇杆」选择对应手柄。列表尚未更新时，可以点击「重新扫描」。

连接 Joy-Con 2

  1. 打开 JoyHarness，按提示允许它访问蓝牙。二代手柄直接在应用中配对。
  2. 在「连接与摇杆」点击「重新扫描」，再长按手柄侧面的 SYNC 按钮。
  3. 等应用显示「已连接」后，在顶部设备菜单选择手柄，并确认已授予辅助功能权限。

02 · 按键与应用方案

  1. 在「按键映射」开启「启用手柄映射」，对照手柄示意图查看按键绑定。
  2. 选择一个按键，分别设置单击、双击和长按。可以绑定快捷键、鼠标动作、常用语和组合动作。
  3. 在「Harness」给应用绑定键位方案。切换到该应用后，JoyHarness 会自动加载它的方案。
  4. 在「连接与摇杆」校准摇杆、调节死区和指针速度，或切换到鼠标模式。

03 · 配置常用语

  1. 在常用语库中编辑两组标题和正文，并为五个位置分配对应条目。
  2. 在「按键映射」将「唤出常用语」绑定到左或右摇杆按下。
  3. 在目标输入框中打开浮层，单击输入内容 1，双击输入内容 2。

04 · 从源码构建

需要 Apple Silicon Mac、macOS 15 或更新版本，以及 Xcode 16+ / Swift 6。进入 JoyHarness 源码目录，运行测试并构建。

scripts/test_all.sh
zsh -ic 'scripts/build_app.sh .build/JoyHarness.app'
open .build/JoyHarness.app

本机构建使用有效的签名身份，详情见 项目构建说明。

05 · 排查连接问题

  • 找不到手柄时，检查电量和蓝牙权限，长按 SYNC 再扫描。二代手柄掉线后也可用这个方式重连。
  • 连了多只手柄时确认选中的是要使用的那只。切换或重连后，先松开按键并让摇杆回中。
  • 手柄已连接但无法发送键盘或鼠标事件时，检查辅助功能权限。一代手柄还需要输入监控权限。

两代手柄的实体兼容性仍待完整验证。遇到连接问题时，可在 GitHub 记录 macOS 版本、手柄型号和应用显示的连接状态。
