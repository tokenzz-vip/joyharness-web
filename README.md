# JoyHarness 官网

JoyHarness 的产品介绍、macOS 下载入口和 Joy-Con 连接指南。

- 官网 [joyharness.tokenzz.vip](https://joyharness.tokenzz.vip/)
- 应用源码和版本发布 [tokenzz-vip/JoyHarness](https://github.com/tokenzz-vip/JoyHarness)

## 本地开发

需要 Python 3。可用 npm 运行以下命令，无需安装项目依赖。

```sh
npm run dev
```

在浏览器访问 http://127.0.0.1:4173/。运行 `npm run build` 可将公开文件复制到 `_site/`，该目录由 GitHub Pages 工作流发布。

首页和指南沿用同级 `rcharness-web` 的布局、样式、内置应用图标和 Tokenzz 关注入口。应用图标与产品截图来自 JoyHarness，可用应用的 `--render-settings` 选项重新导出截图。
